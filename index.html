1. CSS дегеніміз не?

CSS (Cascading Style Sheets) — веб-беттің сыртқы көрінісін (түс, қаріп, орналасу) басқаратын тіл. HTML бетке "қаңқа" берсе, CSS оған "киім" кигізеді.

1994 жылы Хокон Виум Ли енгізген. Артықшылығы: бір CSS файл арқылы жүздеген беттің дизайнын бірден өзгертуге болады.

2. Селекторлар

Селектор — стильдің қай элементке қолданылатынын көрсетеді. 4 негізгі түрі:

ТүріЖазылуыМысал
Элемент бойыншатег атыp { color: black; }
Класс бойыншанүкте ..green { color: green; }
Идентификатор (id)тор ##pink { color: red; }
Контекстікбос орынp b { color: navy; }

Ескерту: бір бетте бір id тек бір рет қана қолданылады, ал class — шексіз рет.

p { } — элемент селекторы (барлық абзацқа әсер етеді)

.green — класс селекторы (тек осы класы барларға)

#pink — идентификатор селекторы (тек бір ғана элементке)

3. Стиль кестелерін қолдану түрлері

ТүріСипаттамасы
Браузер стиліБұл – стандартты стиль парағы. Егер белгілі стиль анықталып, берілмесе, онда осы стандарттар қолданылады.
Қолданушы стиліКез келген қолданушы браузер параметрін өзгерту арқылы өзінің стиль кестесін жаза алады және қолдана алады.
Ендірілген стильStyle атрибутын қолдану арқылы анықталады.
Кіріктірілген стильHTML құжатының ішінде орналасады.
Байланысқан стильҚұжатпен link элементінің көмегімен байланысады.
Импортталған стильСтильдерді импорттайды.

Практика: төмендегі батырманы басып, әр стиль түрінің кодын көр:

<p style="font-size: 120%; font-family: monospace; color: #cd66cc">
  Абзацқа ішкі CSS стильді қолдану
</p>

Ендірілген стиль style атрибутында жазылады, тек сол жалғыз элементке ғана әсер етеді. Ол сыртқы стильдер мен құжат деңгейінің стиліне қарағанда жоғары басымдыққа ие.

  border-width: 6px;

}

<div> және <span>

<div> — жаңа жолдан бастайды (блок), <span> — сол жолда қалады (жол ішінде). Екеуі де жеке бөлікке стиль беру үшін қолданылады.

7. Білімді тексеру

1. HTML дегеніміз не?

HTML (HyperText Markup Language) — гипермәтінді белгілеу тілі, интернеттегі құжаттарды белгілеудің стандартталған тілі. Браузер HTML кодын интерпретациялап, оны экранда форматталған бет түрінде көрсетеді. Мұндай құжаттардың кеңейтілімі — .htm немесе .html.

HTML-дің үш негізгі термині бар: элемент, тег және атрибут.

ТерминМағынасы
ТегҚандай операция орындалуы керегін көрсететін команда, бұрыштық жақшамен < > белгіленеді
ЭлементТег пен оның мазмұнының жиынтығы
АтрибутЭлемент туралы қосымша ақпарат беретін сипаттама

Тегтің екі түрі бар: жұп (мысалы, <b>...</b>) және жұпсыз/дара (мысалы, <br>). Жабылатын тег әрқашан / символынан басталады.

<hr align="right" size="3">

Тегсіз жай мәтін — браузер оны реттеусіз көрсетеді.

Тегпен пішімделген мәтін ✨

2. HTML құжатының құрылымы

Кез келген HTML құжатында міндетті түрде болатын төрт негізгі тег бар:

<html>
  <head>
    <title>Беттің тақырыбы</title>
  </head>
  <body>
    Құжаттың негізгі мазмұны осында
  </body>
</html>

Батырманы басып, әр бөліктің қызметін көр:

Барлық құжат <html> тегімен басталып, </html> тегімен аяқталады. Ол браузерге бұл — HTML беті екенін білдіреді.

3. Мәтінді пішімдеу тегтері

<h1>–<h6> тақырып тегтері (H1 — ең үлкен, H6 — ең кіші), <p> — абзац, <hr> — көлденең сызық, <br> — жол ауыстыру.

Тақырып мәтіні
ТегҚолданылуы
<p align="left/right/center/justify">Абзацты туралайды
<b>, <strong>Қою (қалың) қаріп
<i>, <em>Курсив
<u>, <ins>Асты сызылған мәтін
<s>, <del>Сызылған мәтін
<sub> / <sup>Төменгі / жоғарғы индекс

Физикалық форматтау (<b>) шрифт түрін өзгертеді, ал логикалық форматтау (<strong>) іздеу жүйесіне мәтіннің маңыздылығын білдіреді — екеуі браузерде бірдей көрінеді.

Тізімдер

<ul> — маркерленген тізім, <ol> — нөмірленген тізім, <li> — тізім элементі, <dl>/<dt>/<dd> — көпсатылы тізім.

4. HTML-де кесте құру

Кесте <table> тегімен басталады. <tr> — қатар, <th> — баған тақырыбы (қалыңдатылған), <td> — қарапайым ұяшық.

<table border="1">
  <tr><th>Аты</th><th>Тегі</th></tr>
  <tr><td>Айнұр</td><td>Исаева</td></tr>
</table>
АтыТегі
АйнұрИсаева
АтрибутҚызметі
borderКесте жиегінің қалыңдығы
colspanБірнеше бағанды біріктіру
rowspanБірнеше жолды біріктіру
cellpaddingҰяшық ішіндегі бос орын
captionКестенің тақырыбы (жеке тег)

5. HTML тілінде сілтемелер

Сілтеме <a>...</a> (anchor — якорь) тегімен жасалады.

ТүріКод мысалы
Сыртқы сілтеме<a href="https://kk.wikipedia.org">Уикипедия</a>
Ішкі сілтеме (якорь)<a href="#hquiz">Тестке өту</a>
Электрондық пошта<a href="mailto:a@mail.com">Пошта</a>
Суретті сілтеме<a href="..."><img src="..."></a>

Мысалы, осы батырма — ішкі сілтеме, ол сені осы беттің тесті бар бөліміне апарады: Тестке өту ↓

Үнсіз келісім бойынша сілтеме түстері: link — қаралмаған (көк), vlink — қаралған (күлгін), alink — белсенді (қызыл).

6. HTML-де мультимедиа

<img src="..."> — сурет кірістіретін жұпсыз тег. Web-те қолданылатын форматтар: GIF, JPG, PNG.

АтрибутҚызметі
srcСурет мекенжайы (міндетті)
altСурет жүктелмесе шығатын мәтін
width / heightЕні мен биіктігі
borderЖақтау қалыңдығы

<audio> және <video> тегтері дыбыс пен бейнені қосу үшін қолданылады:

<audio src="sound.mp3" controls></audio>
<video src="video.mp4" width="320" controls></video>
АтрибутҚызметі
controlsБасқару панелін қосады
autoplayАвтоматты ойнатады
loopҚайталап ойнатады
poster(тек video) ойнатылмағанда көрінетін сурет
